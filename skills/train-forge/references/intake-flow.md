# Progressive intake decision flow

Use this flow before creating a formal program for a new person or materially different goal. Do not ask for information already supplied.

## Conversation rules

- Ask 1–3 short, logically grouped questions per turn.
- Use clear choices for classification and goals, while always allowing free-text clarification, “不知道”, “暂不回答”, and “按现有信息出计划”.
- Explain why a sensitive or unusual question matters.
- Treat every answer as optional. Distinguish high-impact questions from nice-to-have measurements without calling them mandatory.
- Do not force body-fat percentage, one-repetition maximums, laboratory tests, or wearable data.
- Convert unknown performance values into a first-session calibration task.
- Stop the questionnaire and address safety when a red flag appears.
- After each round, offer two paths: continue improving accuracy or generate the plan now.
- Record declined items as “not provided” and do not ask them again unless new symptoms or goals make them safety-critical.
- Generate a plan at the best justified precision from the available information; do not block ordinary training because optional data is absent.

## Dynamic stopping and precision tiers

Ask high-impact questions first and stop when the user wants to proceed. Classify the output:

| Precision | Typical available information | Output rule |
| --- | --- | --- |
| Basic | Goal plus a small amount of context such as height/weight or available days | Give a conservative starter plan, broad ranges, gym/home alternatives when equipment is unknown, no maximal/high-risk work, explicit assumptions, and session-1 calibration |
| Standard | Goal, participant route, experience/current activity, schedule/equipment, and pain/restriction status | Give a complete individualized course with normal progression and monitoring |
| Enhanced | Standard profile plus reliable performance logs, recovery trends, body metrics, medical restrictions, competition calendar, or coach/testing data | Refine load, volume, timing, tests, taper, and substitutions without pretending the data is perfect |

No medical report is required for any tier. Absence of a report is not itself a yellow or red status. If health screening is declined, mark it “not assessed,” use conservative prescriptions, and avoid implying medical clearance.

Prioritize missing data in this order:

1. Explicit red flags or clinician restrictions
2. Primary goal and participant route
3. Current training/activity and experience
4. Schedule, equipment, and environment
5. Pain/injury information
6. Relevant capacity anchor
7. Recovery, preferences, and adherence
8. Optional body composition, wearables, detailed logs, and reports

## Stage 1 — participant route

Ask this first when the route is not already clear:

> Which best describes you right now?

| Route | Definition | Next branch |
| --- | --- | --- |
| Competitive/professional athlete | Competition, selection, ranking, result, contract, or performance calendar materially drives training | Stage 5A and sport-demand analysis |
| Recreational/amateur sport participant | Practices a specific sport for enjoyment, health, skill, or occasional events | Stage 5B and proportionate sport-demand analysis |
| Fitness-only / no primary sport | Main need is health, muscle, strength, fat loss, conditioning, mobility, appearance, or daily function | Stage 5C; do not force sport analysis |

Do not equate “amateur” with untrained. Ask experience and current workload separately.

Allow “不确定 / 跳过”. If skipped, infer only from what the user has said; otherwise mark the route undetermined and use a general-fitness starter structure.

If the user is returning after surgery, injury, pregnancy/postpartum, prolonged illness, or major deconditioning, retain the route above but add a return-to-exercise flag and complete safety screening before programming.

## Stage 2 — goal and horizon

Ask for one primary outcome and up to two secondary outcomes:

- Health and sustainable activity
- Muscle gain
- Maximal or general strength
- Fat loss/body recomposition
- Cardiorespiratory fitness or endurance
- Speed, explosiveness, or agility
- Mobility, balance, or daily function
- Sport skill/performance support
- Event, test, selection, or competition result
- Return to regular training under appropriate clearance

Ask for the desired horizon, event date, or preferred review date. If goals conflict, ask the user to rank them rather than silently treating all as equal.

## Stage 3 — universal profile and logistics

Invite as relevant; the user may skip any item:

- Age
- Height and current weight; recent trend if relevant
- Sex-related or pregnancy/postpartum information only when it affects screening or programming
- Occupation/study pattern and typical daily movement
- Training history, current weekly activity, and longest recent break
- Available days and minutes per session
- Home, commercial gym, club, field/court, pool, track, outdoor, or mixed setting
- Available equipment and access to coaches/partners
- Travel, shift work, childcare, fasting, or fixed schedule constraints

Always optional: waist, body-fat estimate and method, resting heart-rate trend, blood pressure, wearable data, progress photos, detailed food logs, and medical reports.

## Stage 4 — health and safety

Read `intake-and-safety.md` and invite answers to:

1. Is there current pain, swelling, numbness, weakness, dizziness, chest symptoms, unusual breathlessness, or symptoms after head impact?
2. Are there important injuries, operations, diagnosed conditions, medication effects, pregnancy/postpartum considerations, or clinician restrictions?
3. Is there a recent medical/physical-exam report or clinician restriction? “没有报告 / 不清楚 / 暂不提供” is a complete valid answer.

If a report is supplied, preserve its date, units, reference ranges, and clinician comments. Do not diagnose from it.

If these questions are skipped, do not claim the person is medically cleared. Use “screening not assessed,” avoid maximal/high-risk work, and include a short stop-symptom notice. A reported red flag overrides the option to continue hard training.

## Stage 5A — competitive/professional athlete

Collect only the sport-relevant fields:

- Exact sport, discipline/event, position/role, weight class/apparatus/ruleset
- Level, selection criteria, current season phase, competitions and travel
- Technical/tactical practices, matches/events, and coach plan
- Role-specific performance tests and recent results
- Strength, speed/power, endurance, movement, body-composition, and injury constraints
- Recovery resources and what the sport coach already controls

Use `sport-demand-analysis.md`. Physical preparation must fit the sport calendar and technical plan.

## Stage 5B — recreational/amateur sport participant

Collect:

- Exact sport/discipline and experience
- Sessions per week and typical intensity/duration
- Whether health, enjoyment, skill, appearance, or performance is the real priority
- Any upcoming event, match, trip, grade, or personal milestone
- Coaching access and current performance anchor
- Sport-related pain or repetitive-load concern

Use a proportionate sport-demand analysis. Do not build an elite competition program for someone seeking enjoyable, sustainable participation.

## Stage 5C — fitness-only / no primary sport

Collect:

- Ranked goal: health, muscle, strength, recomposition/fat loss, conditioning, mobility/balance, appearance, or daily function
- Training status: never trained, returning, under 6 months, 6–24 months, or over 2 years of consistent training
- Current routine and why previous plans stopped
- Comfortable movement/capacity anchors such as push-ups, machine/free-weight work sets, squat/hinge confidence, walking/jogging/cycling duration, stairs, balance, or daily steps
- Gym/home equipment and willingness to use machines, free weights, classes, cardio equipment, body-weight training, or outdoor activity
- Exercise preferences, dislikes, confidence, and desired session style
- Nutrition/body-weight goal only when relevant; avoid requiring calorie tracking

Default ordinary beginners toward simple full-body training 2–3 times per week plus recoverable aerobic activity, not an advanced bodybuilding split. Choose another structure when experience, preference, availability, or goal justifies it.

## Stage 6 — recovery and adherence

Ask only what remains unknown:

- Typical sleep duration and consistency
- Work/life stress and recovery time
- Daily movement/step baseline
- Preferred training times and realistic attendance
- Exercises or environments the person enjoys, fears, or refuses
- Social support, coaching, and previous barriers
- Eating pattern, protein access, and weight trend when body composition is a goal

Treat adherence as a programming variable. A theoretically optimal plan that the person will not repeat is not optimal.

## Stage 7 — profile summary and choice

Before the formal plan, show a compact card:

| Field | Current value |
| --- | --- |
| Participant route | Competitive / recreational sport / fitness-only |
| Primary and secondary goals | Ranked |
| Baseline | Age, height, weight, experience, current activity |
| Schedule and equipment | Realistic weekly capacity |
| Health status | Green / yellow / red / not assessed, with constraints |
| Performance anchors | Known values or session-1 calibrations |
| Recovery and adherence | Main limits and preferences |
| Assumptions / missing items | Explicit |
| Plan precision | Basic / standard / enhanced |

Offer:

1. Correct or add anything important.
2. Continue with another short question round for more accuracy.
3. Generate the plan now from current information.

Do not require explicit confirmation when the user has already said to proceed. Generate the report with assumptions, unknowns, and calibration steps visible. The user can provide more data later and the plan should update without restarting the intake.

## Conditional question bank

Use only questions that change decisions:

| Need | Useful details |
| --- | --- |
| Muscle gain | Target areas, current weekly sets, stable work-set loads, appetite/weight trend |
| Strength | Priority lifts or tasks, work sets, technique confidence, equipment |
| Fat loss/recomposition | Seven-day weight trend, waist, steps, eating pattern, previous rate of loss |
| Conditioning/endurance | Continuous easy duration, recent pace/power/time trial, preferred mode, impact tolerance |
| Speed/power | Sprint/jump/throw history, surface, footwear, exposure to maximal efforts |
| Mobility/balance/function | Exact task or range that is limited, falls/balance confidence, symptoms |
| Sport performance | Event/role metrics, technical volume, competition calendar, coach priorities |
| Older/deconditioned beginner | Walking/stair tolerance, sit-to-stand, balance, fall history, confidence |
| Youth | Growth/development context, supervision, school/sport schedule, nutrition adequacy |
