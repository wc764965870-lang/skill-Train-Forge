# 拳击训练视觉报告示例

这是 Train Forge 生成视觉训练报告的可运行参考实现。示例展示一套匿名的 12 周拳击、力量与体成分重组计划。

## 已实现

- 点击周一至周日，课程时间线与动作库同步切换
- 区分“热身、爆发激活、主力量、辅助超级组”等训练模块与具体动作
- 周一至周五的所有具体训练项目均有对应动作卡
- 真人视频、双姿态照片和原创教学图均保存在本地目录
- 动作卡包含执行步骤、常见错误、器械提示及素材来源
- 支持离线缓存和添加到手机主屏幕
- 适配桌面与手机宽度

## 查看方式

把 `dist` 目录作为静态网站根目录打开。首次在线载入并显示“完整动作库已保存 · 可断网使用”后，该设备可以在断网状态下继续查看。

直接双击 `dist/index.html` 可以浏览主要内容，但浏览器只有在网页地址环境中才会启用离线缓存和主屏幕安装。

## 素材

动作卡内保留每项第三方素材的来源页面和授权说明。素材来自 Wikimedia Commons、Pexels 与采用 The Unlicense 的 free-exercise-db；药球旋转侧抛教学图为本项目生成的原创示意图。继续分发或修改时，请保留来源信息并重新核对对应授权条款。
